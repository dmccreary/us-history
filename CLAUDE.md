# CLAUDE.md — U.S. History Intelligent Textbook

This site is a level 2.9 interactive intelligent textbook built
with the mkdocs-material tools.

GitHub site: `https://dmccreary.github.io/us-history/`
Publishing site: `https://dmccreary.github.io/us-history/`

## Content Generation

When generating or editing any chapter content, load and follow all rules in
[`CONTENT-GENERATION-GUIDE.md`](CONTENT-GENERATION-GUIDE.md).

That file covers:

- Liberty the Bald Eagle mascot (file index, admonition format, placement rules, do's and don'ts)
- Markdown formatting rules (currency escaping, LaTeX math conflicts)
